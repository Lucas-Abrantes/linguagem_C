## 📚 Conteúdo da Disciplina

### Unidade II — Introdução à Linguagem C

Nesta unidade, será apresentada a linguagem C, abordando seus principais elementos e estruturas fundamentais para o desenvolvimento de algoritmos.

#### Linguagem C: elementos básicos

* Diretivas
* Constantes
* Variáveis
* Identificadores
* Tipos de dados
* Declaração de variáveis
* Operadores
* Expressões

#### Linguagem C: estruturas de decisão

* `if`
* `if-else`
* `if` encadeado
* `switch`

#### Linguagem C: estruturas de repetição

* `while`
* `do-while`
* `for`

## 💻 Linguagem utilizada

Os exemplos e exercícios deste repositório serão desenvolvidos utilizando a linguagem:

```text
C
```

A compilação dos programas pode ser realizada utilizando o **GCC**.

Exemplo:

```bash
gcc programa.c -o programa
```

Execução no Windows:

```bash
.\programa.exe
```

Execução no Linux/macOS:

```bash
./programa
```

## 🎯 Objetivo

Ao longo das unidades, serão desenvolvidos conhecimentos fundamentais para a construção de algoritmos e programas em C, desde os elementos básicos da linguagem até a utilização de **estruturas de decisão, repetição, funções, vetores e matrizes**.
